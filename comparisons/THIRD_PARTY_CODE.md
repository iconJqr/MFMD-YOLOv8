# Third-party code and licenses

The comparison models remain the property of their respective upstream projects. This release does not copy their complete repositories, pretrained weights, or generated checkpoints.

For each reproduction run, record the repository URL, immutable commit hash or release tag, license, model configuration, pretrained checkpoint source, and framework version. Optimizer settings reported in manuscript Table 4 are transcribed in `model_registry.yaml`; preserve the upstream license and attribution when copying any configuration file.

Candidate upstream projects identified from the manuscript or local code inventory include:

- Ultralytics YOLOv5: `https://github.com/ultralytics/yolov5`
- Ultralytics: `https://github.com/ultralytics/ultralytics`
- YOLOv10: `https://github.com/THU-MIG/yolov10`
- MMDetection/RTMDet: `https://github.com/open-mmlab/mmdetection`

These URLs identify likely upstream projects. The repository revision used for a reproduction run should be recorded alongside its results.
