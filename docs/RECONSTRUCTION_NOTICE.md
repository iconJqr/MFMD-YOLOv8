# 关于缺失实验资料的重建说明

本发布包包含四类材料：

1. 可以直接由代码或论文逐项确认的实现，例如模型 YAML、RCS-OSA、BRA、CIoU/WIoU v3、DFL 和评价脚本；
2. 从论文表格或正文逐项转录的数值和环境，标记为 `manuscript_reported` 或具体表格来源；
3. 根据《定稿.docx》重建的实验协议、数据处理模板和日志汇总工具，标记为 `reconstructed_from_manuscript`；
4. 必须依赖重新运行才能填写的空白记录，标记为 `measured_run_pending`。

第二类材料仅证明论文中出现过该表述或数值，不证明当前代码重新得到了相同结果。第三类材料不是原始数据的恢复，也不是原始运行日志的替代品；它们只把论文中明确写出的流程转化为可执行模板，便于作者重新整理遗失资料或在拥有数据后重新运行。第四类材料必须保持空白，直到真实实验输出可供核验。

以下内容目前不能由论文单独恢复：原始家具照片、原始标注文件、匿名家具编号与照片的对应关系、每个随机种子的完整训练日志、第三方模型的最终 commit、真实 Grad-CAM 数值和真实逐 epoch 曲线。因此，发布时不得把模板中的空值、示例值或论文转录值描述为重新生成的实验结果。

论文中已经报告的汇总数值另存于 `comparisons/paper_reported_results.csv`，该文件的 `provenance` 字段明确表示其来源是论文表格。

合成演示数据只用于安装和前向传播检查，标记为 `synthetic_smoke_test_only`，不得用于论文性能、消融、鲁棒性或可解释性结论。
