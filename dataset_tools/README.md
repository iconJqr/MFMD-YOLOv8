# Dataset preparation tools

这些脚本把论文中的数据流程整理为可执行入口，但不包含私有家具图像和标注。

论文中可直接对应的处理约束：

- 以家具来源组为划分单位，不能把同一家具的照片、ROI 或派生图像分到不同子集；
- 划分目标约为 8:1:1，划分种子为 42；
- ROI 手动保留完整主体及上下文边缘，主体宽高扩展 10%–15%；
- 长边等比例缩放到 640 像素，短边用 RGB `(114, 114, 114)` 填充；
- 最终标注坐标位于 640×640 图像上；
- 离线扩增只用于训练集，论文记录为 1051 张原始训练图像和 3153 张扩增图像；
- 验证集和内部测试集不做扩增。

`split_by_group.py` 需要一个由作者整理的匿名 manifest；它不会从图像内容推断家具来源。`offline_augmentation.py` 实现论文中公开的操作范围，但随机操作的具体组合仍应与原始导出记录核对。
